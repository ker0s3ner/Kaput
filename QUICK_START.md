## 🎯 Basic Workflow

```
1. Start app
2. See main menu with 18 options in 3-column grid
3. Navigate using arrow keys (↑↓←→)
4. Press ENTER to enter a category → Submenu appears
5. Navigate submenu with ↑↓ keys
6. Press ENTER to run a tool
7. Use ESC to go back to main menu
8. Press q to quit completely
```
